# Beam macro clip (retired from the tour)

`tour-beam` and `tour-beam-sm` are the frames of `ai-brief/source/tour-beam-macro.mp4`, the first version of tour chapter 3.
It starts on the same wide gate framing as the current sensor clip but pushes in on the beam post (the two-lens transmitter) with a thin pink beam.

It was replaced by `tour-sensor` (`ai-brief/source/tour-sensor-pushin.mp4`): a brighter, on-brand violet beam that ends on the wall sensor.

To use it again, move both folders back into `public/frames/` and either point the chapter at `tour-beam`
(change `data-frames` on the third `canvas.tour__clip` in `index.html`) or add it as a fourth chapter
(a canvas, an article and a stepper button; see "Adding or re-pointing a tour chapter" in the main README).
