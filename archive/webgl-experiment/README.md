# Archived: real-time WebGL version

A night-time three.js scene: procedural 3D van with the livery, steering wheels and spring suspension, a control-room
radar view, premises with beams and a gate, all driven by one GSAP + Lenis scroll timeline.

Not part of the build. To run it again: `npm i three`, copy these files back over `src/` and `index.html`, and use
`vite.config.js` here (it adds the dev-only frame-capture endpoint). `ai-brief/` holds the guide frames it produced.
